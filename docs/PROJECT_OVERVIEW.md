# Project Overview

## 项目名称
PC 私域直播伴侣（MVP）

## 项目目标
在 40 天内，由单人完成一个基于 C++ / Qt 的 PC 端直播伴侣最小可用版本（MVP）。

该版本的目标是：
- 能稳定推流
- 能支持基础场景与画布
- 能满足私域直播的核心使用需求

## 项目定位
- 私域直播工具
- 面向非专业主播
- 强调稳定、易用、可控

## 明确不是目标
- 不做 OBS 替代品
- 不追求高度通用
- 不支持插件生态
- 不支持复杂特效

## 技术栈
- C++17
- Qt
- FFmpeg
- WebRTC Audio Processing Module
